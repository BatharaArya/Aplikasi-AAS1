Fitur Pembelajaran Utama

Aktifkan mode ini untuk melihat bagian dalam spektrofotometer. Bodi alat akan menjadi transparan sehingga jalur cahaya HCL, api, dan detektor terlihat jelas.

Kontrol Instrumen

Hukum Beer-Lambert

A = ε · b · c

A = Absorbansi (tidak bersatuan)
ε = Absorptivitas Molar (L·mol⁻¹·cm⁻¹)
b = Lebar celah api / panjang lintasan (cm)
c = Konsentrasi sampel (ppm / M)

Pada AAS, sumber cahaya Hollow Cathode Lamp (HCL) memancarkan sinar dengan panjang gelombang spesifik (misal 324.7 nm untuk Tembaga/Cu). Saat sampel diuapkan dalam nyala api, senyawa terurai menjadi atom-atom bebas pada keadaan dasar. Atom-atom ini akan menyerap energi cahaya dari HCL. Semakin banyak atom (konsentrasi tinggi), semakin banyak cahaya yang diserap, sehingga intensitas cahaya yang sampai ke detektor berkurang (Absorbansi naik).

Proses Atomisasi (Flame)

  • Nebulisasi: Sampel cair dihisap dan diubah menjadi kabut aerosol.
  • Desolvasi: Panas api menguapkan pelarut, meninggalkan partikel garam padat.
  • Volatilisasi: Garam padat melebur dan menguap menjadi molekul gas.
  • Disosiasi: Energi termal memecah ikatan molekul menjadi atom bebas yang siap menyerap cahaya.
